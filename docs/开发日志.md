### 做了什么
- Pyodide 本地打包：`scripts/copy-pyodide.mjs` 把核心文件（pyodide.js / pyodide.mjs / pyodide.asm.mjs / pyodide.asm.wasm / python_stdlib.zip / pyodide-lock.json）从 node_modules 拷入 `public/pyodide/`；UMD script 注入，indexURL 相对 `document.baseURI` 解析，兼容子路径部署；全程不依赖境外 CDN，评委无需 VPN。

- 舞台桥接 `src/runtime/bridge.ts`：生成的 Python 以 `await stage.xxx(...)` 驱动 JS 舞台；实现移动/转向/面向/坐标/增减坐标/反弹/说/说几秒/显示/隐藏/大小/等待/tick/广播/停止全部指令；Scratch 语义（方向 90=右、dx=steps·sin、dy=steps·cos；反弹左右取反、上下 180-方向；"说"不带秒数持续显示）。

- 键盘事件：window keydown 映射空格/方向键/字母；输入框聚焦时与停止后忽略。

## 任务 9：联调与修错（2026-11-16）

### 做了什么
- 走通完整链路：搭积木 → 代码视图 → Pyodide 运行 → 舞台效果 → 大屏镜像 → 自动保存/导出/导入，全部实测通过。
- 修复 1（生成代码缺 import）：内置积木（math_random_int / math_modulo / math_arithmetic 幂运算等）在生成期把 import 依赖写入 `pythonGenerator.definitions_`，但装配脚本时未输出 → 运行 NameError。改为装配完成后收集 definitions_ 统一置顶（类型声明为 protected，按结构类型读取）。
- 修复 2（NaN 坐标污染，本轮最重要的 bug）：用未赋值变量跑脚本后精灵 x/y 变 NaN（存档里为 null）。探针（monkey-patch `stage.patch` + `Error().stack`）定位到 bridge.move；根因是 **Pyodide 把 Python None 传为 JS undefined**，`Number(undefined)=NaN` 沿指令链污染坐标。三层修复：

   空闲（首次/重置后/失效后）→直接开始（不再先重置）；运行→暂停（冻结保留状态）；
   暂停→续跑；结束→轻量重启（直接重新派发绿旗脚本，不重置角色位置）。
   绿旗彻底不再调用 reset()；重置按钮为唯一重置入口（终止协程＋释放注入对象＋
   止声＋清错误卡片＋精灵回保存的初始基准 resetToInitial，R14 patchSaved 定义）。
2. 结束态轻量重启（执行方定）：注册表在结束态仍有效（编辑会经 R4 invalidate
   回到空闲态），故直接 dispatchFlag 重派绿旗脚本，不重跑顶层代码——
   变量跨重启保留（贴近 Scratch 语义），且无 Pyodide 往返、响应即时。
3. 调度器状态判定完善（`runtime/bridge.ts` Scheduler）：新增 pending 计数覆盖
   "派发→Python 协程启动"间隙＋active  getter（busy>0 || pending>0），
   防止间隙内绿旗被误判为结束态而重复派发；暂停按钮在结束态不再进入
   "无对象可冻结"的空暂停；begin/stop 同步清零 pending。
4. 看门狗预算修复（验收中发现的真实缺陷）：结束态停留/等待事件期间的时间
   不是脚本执行，但原 lastYield 停留在上次让出——重启后第一轮 loop_guard
   即误报 ScriptTimeoutError。修复：spawn() 在空闲后首次派发时 noteYield()
   重置预算；同时消除了"结束一段时间后按键/广播触发脚本"的同源隐患。
5. 注册期守卫：run() 增加 starting 标记，加载与注册期间绿旗不响应，
   防止对半建成的注册表重复派发。
6. 入口统一与文案：帽积木点击（R2）、代码视图事件行、大屏遥控本就转交同一
   flag()，语义自动统一；绿旗按钮 title（主页面＋大屏页）与相关注释更新为
   R18 语义（开始/暂停/续跑，不重置位置）。

## 第三轮 R19：编辑状态与运行状态分离（2026-11-17）

### 做了什么
1. 状态门控梳理确认（R18 基础上）：舞台拖拽门 canDrag = 非运行且非吸色——
   运行态（busy>0）与暂停态（协程冻结但 busy>0，暂停仍属运行状态）均禁拖；
   重置→stopped→running=false→恢复编辑态拖拽。运行/暂停期间画布 pointerdown
   直接早退，不触发暂停/重置/选中任何副作用；位置完全由程序控制。
2. 拖拽收尾与运行态解耦（`stage/index.ts` endDrag，本轮唯一代码改动）：
   原实现拖拽结束调 onStructuralChange（自动保存＋R4 invalidate）——
   invalidate 会在结束态清掉事件注册表，违背"拖拽不得影响程序运行状态"。

   拖拽是基准编辑而非结构变化，任何状态下都不终止运行时。
3. 编辑态拖拽更新保存基准（R14 已预置，本轮验证闭环）：拖拽结束即把落点
   写入 initial 基准（重置回到拖拽后位置），并经自动保存持久化——
